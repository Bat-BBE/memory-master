# 🧠 Memory Master

**Memory Master** нь тоглогчийн ой тогтоолт, анхаарал төвлөрөл, ажиглах чадварыг сорих зориулалттай, орчин үеийн дизайн бүхий веб тоглоом юм. Тоглогч хөзрүүдийг ээлжлэн эргүүлж, ижил зурагтай хосуудыг олсноор түвшнүүдийг давж, оноо цуглуулж, өөрийн рекордыг ахиулна.

## 🎯 1. Төслийн гол зорилго

- Ой тогтоолт болон анхаарал төвлөрүүлэх чадварыг сорьсон сонирхолтой тоглоом бүтээх.
- Хэрэглэгчийг түвшин ахих тусам илүү хэцүү сорилттой тулгарах боломжтой болгох.
- Энгийн тоглоомын механикийг орчин үеийн UI/UX дизайнтай хослуулах.
- Компьютер болон гар утасны веб хөтөч дээр суулгалтгүй ажиллуулах.
- Тоглогчийн оноо, амжилт, түвшний ахицыг хадгалах.
- GitHub Pages ашиглан тоглоомыг үнэгүй нийтлэх.

## 🎮 2. Тоглоомын үндсэн дүрэм

1. Тоглогч эхлэхдээ нээлттэй байгаа түвшнүүдээс сонгоно.
2. Тоглоомын самбар дээр ижил зурагтай хос хөзрүүд санамсаргүй байрлана.
3. Тоглогч нэг удаад хоёр хөзөр эргүүлнэ.
4. Хоёр хөзөр ижил зурагтай бол хос олсонд тооцно.
5. Хоёр хөзөр өөр зурагтай бол богино хугацааны дараа буцааж хаана.
6. Бүх хосыг хугацаа дуусахаас өмнө олбол түвшнийг давна.
7. Хугацаа дуусвал тоглоом дуусаж, дахин оролдох боломжтой.
8. Амжилттай дуусгасан түвшнээс дараагийн түвшний түгжээг нээнэ.
9. Тоглогч оноо болон гүйцэтгэлээсээ хамааран 1–3 од авна.

## 🏆 3. Түвшний бүтэц

Тоглоом нийт **20 түвшинтэй** байна.

| Түвшин | Ангилал | Хөзрийн тоо | Хосын тоо |
|---|---|---:|---:|
| 1–2 | Эхлэгч | 4–6 | 2–3 |
| 3–4 | Энгийн | 16 | 8 |
| 5–6 | Дунд | 20 | 10 |
| 7–10 | Хэцүү | 30 | 15 |
| 11–18 | Master | 36 | 18 |
| 19 | Master (boss) | 42 | 21 |
| 20 | Master (boss) | 48 | 24 |

Түвшин ахих тусам хугацаа, нүүдлийн үр ашиг, анхаарал шаардсан сорилтууд нэмэгдэнэ. Түвшин бүр өөрийн нэр, дүрс, хугацаа, хөзрийн зохион байгуулалттай байна.

## ⚙️ 4. Функциональ шаардлага

### 4.1. Үндсэн тоглоом
- Хөзрүүдийг эргүүлэх болон буцааж хаах.
- Ижил хосыг автоматаар таних.
- Таарсан хөзрүүдийг дахин сонгох боломжгүй болгох.
- Нийт хос болон олсон хосын тоог харуулах.
- Хугацааг секундээр тоолж харуулах.
- Нүүдэл, оноо болон дараалсан зөв хосыг бүртгэх.

### 4.2. Онооны систем
- Зөв хос бүрд үндсэн оноо олгох.
- Дараалсан зөв хос бүрд нэмэлт оноо өгөх.
- Үлдсэн хугацаа болон үр ашигтай нүүдлээс нэмэлт оноо тооцох.
- Гүйцэтгэлд үндэслэн 1–3 од олгох.
- Түвшин бүрийн хамгийн өндөр оноог хадгалах.

### 4.3. Түвшин ба ахиц
- Эхний түвшин тоглох боломжтой байна.
- Дараагийн түвшин өмнөх түвшнийг амжилттай дуусгасны дараа нээгдэнэ.
- Түвшин бүрийн амжилт, од, өндөр оноог бүртгэнэ.
- Тоглогч өмнө нь нээсэн түвшнээ дахин тоглох боломжтой байна.

### 4.4. Туслах боломжууд
- Тоглоомыг түр зогсоох, үргэлжлүүлэх.
- Одоогийн түвшнийг дахин эхлүүлэх.
- Нэг хос олоход туслах hint функц ашиглах.
- Дууны эффектийг асаах, унтраах.
- Тоглоомын төгсгөлийн дэлгэцээс дахин тоглох эсвэл дараагийн түвшинд орох.

### 4.5. Өгөгдөл хадгалах
- Нийт амжилттай давсан түвшин.
- Нийт ялалтын тоо.
- Нийт дээд оноо.
- Түвшин бүрийн хамгийн өндөр оноо.
- Түвшин бүрийн авсан од.
- Ахицын өгөгдлийг `localStorage` ашиглан хадгална.

## 🎨 5. UI/UX шаардлага

- Dark болон Neon өнгөний хослол бүхий орчин үеийн дизайн.
- Цэнхэр, нил ягаан, cyan болон алтлаг accent өнгө.
- Хөзөр эргүүлэх жигд animation.
- Оноо, хугацаа, нүүдэл болон хосын тоог ойлгомжтой харуулах.
- Start, Pause, Restart, Win болон Game Over дэлгэцтэй байх.
- Гар утас, таблет, компьютерийн дэлгэцэд responsive байх.
- Товчлуурууд ойлгомжтой, хэрэглэхэд хялбар байх.
- Animation болон хөдөлгөөнд мэдрэг хэрэглэгчдэд зориулсан `prefers-reduced-motion` тохиргоог дэмжих.

## 🛠️ 6. Технологийн шаардлага

| Технологи | Зориулалт |
|---|---|
| HTML5 | Веб хуудасны бүтэц |
| CSS3 | Дизайн, responsive layout, animation |
| JavaScript | Тоглоомын дүрэм, оноо, таймер, түвшний удирдлага |
| DOM API | Хөзөр болон дэлгэцийн элементүүдийг удирдах |
| LocalStorage | Тоглогчийн ахиц хадгалах |
| Web Audio API | Дууны эффект |
| WebGL / Three.js r149 | 3D хөзөр, гэрэлтүүлэг, particle эффект (`js/vendor/three.min.js`, интернетгүй ажиллана) |

### 3D график давхарга
- `js/gfx-core.js` — renderer, хөзрийн geometry, texture, гэрэл, spring animation, нягтралыг автоматаар бууруулдаг governor.
- `js/board3d.js` — тоглоомын самбарыг 3D-ээр зурна. Жинхэнэ `.memory-card` товчлуурууд дээрээ үл харагдах байдлаар үлддэг тул тоглоомын логик, keyboard, aria огт өөрчлөгдөөгүй. Хөдөлгөөнгүй үед GPU ажиллахгүй (on-demand render).
- `js/hero3d.js` — нүүр хуудасны 3D орб болон тойрон эргэх хөзрүүд. Зөвхөн дэлгэц дээр харагдаж байх үед render хийнэ.
- WebGL дэмжихгүй browser дээр хуучин CSS хөзрүүд автоматаар ажиллана.
| Git / GitHub | Хувилбарын удирдлага, эх код хадгалах |
| GitHub Pages | Веб тоглоомыг нийтлэх |

### Техникийн хязгаарлалт
- Backend сервер шаардлагагүй.
- Database сервер шаардлагагүй.
- Тоглоомын үндсэн хувилбарыг нэг `index.html` файлд багтааж болно.
- Интернетгүй үед ч локал файл хэлбэрээр тоглох боломжтой.
- Ахиц хадгалалт нь тухайн browser болон төхөөрөмжид хамаарна.
- Multiplayer болон төхөөрөмж хоорондын өгөгдөл синхрончлох боломж нь эхний хувилбарт орохгүй.

## 🚀 8. Ажиллуулах болон нийтлэх

### Локал компьютер дээр
1. Repository-г clone хийнэ.
2. `index.html` файлыг browser дээр нээнэ.
3. Эсвэл VS Code-ийн Live Server ашиглан ажиллуулна.

### GitHub Pages дээр
1. GitHub repository үүсгэнэ.
2. `index.html` болон `README.md` файлуудаа push хийнэ.
3. Repository-ийн **Settings → Pages** хэсэгт орно.
4. `Deploy from a branch` сонгоно.
5. Branch: `main`, Folder: `/ (root)` сонгоод хадгална.
6. GitHub Pages-ээс үүссэн URL-аар тоглоомоо нээнэ.

## 📌 Төслийн дүгнэлт

Memory Master нь HTML, CSS, JavaScript ашиглан хөгжүүлж болох, серверийн нэмэлт зардалгүй, хурдан нийтлэх боломжтой веб тоглоом юм. Үндсэн зорилго нь энгийн механикийг сонирхолтой түвшин ахих систем, оноо, амжилт, чанартай UI/UX-тэй хослуулан хэрэглэгчийг дахин тоглох хүсэлтэй болгоход оршино.

**Төслийн төрөл:** Browser-based casual game  
**Хөгжүүлэлтийн түвшин:** Beginner–Intermediate  
**Нийт түвшин:** 20  
**Нийтлэх платформ:** GitHub Pages  
**Лиценз:** Нийтлэхдээ өөрийн сонгосон лицензийг тодорхойлно.
